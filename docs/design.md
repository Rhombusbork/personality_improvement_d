# 설계: 훈련 웹앱 (MVP: 불확실성 돌아보기)

## 1. 목적
매일 같은 형식으로 하는 심리 훈련을 웹앱이 진행해 준다. 사용자는 정해진 순서대로 답하기만 하면 되고, 결과는 텍스트 파일 하나로 다운로드한다.

MVP는 **불확실성 돌아보기** 하나만 구현한다. 나머지 훈련은 같은 구조로 나중에 추가한다.

## 2. 원칙
- **매일 똑같은 흐름.** 화면 순서, 질문 문구, 출력 형식이 바뀌지 않는다. 사용자는 반복으로 익힌다.
- **판단하지 않는 문구.** "실패", "잘했어요" 같은 평가 표현을 쓰지 않는다. "못 찾음", "아직 모름", "확실성 추구를 했다"도 정상적인 답이다.
- **고르기에 부담을 주지 않는다.** 추천, 점수, 최적 선택 안내를 넣지 않는다.
- **데이터는 내 계정 밖으로 나가지 않는다.** 서버, 계정, 분석 도구 없음. 결과는 다운로드하거나, 설정에서 연결한 내 Apps Script를 통해 월별 Google Docs에 저장한다 (4.6절).
- **타이머는 안내일 뿐이다.** 시간이 끝나면 다음 단계로 가자고 알려 주되, 입력을 막지 않는다.

## 3. 기술 스택
- 순수 HTML, CSS, JavaScript (ES 모듈). 빌드 도구와 의존성 없음.
- 배포: GitHub Pages (main 브랜치 루트).
- 임시 저장: `localStorage` (작성 중인 내용을 새로고침해도 잃지 않도록). 모든 접근은 try/catch로 감싸고, 실패해도 앱은 정상 동작한다.
- 테스트: `node --test` (의존성 없음). 순수 함수만 테스트한다.

## 4. 화면 구성

### 4.1 홈
제목과 훈련 버튼 목록. 하루 훈련은 아래 4단계 순서로 진행하며, 버튼에 순서 번호를 붙인다.

| 순서 | 버튼 | 상태 |
|---|---|---|
| 1 | 신체 훈련 | 사용 가능 |
| 2 | 불확실성 훈련 (= 불확실성 돌아보기) | 사용 가능 |
| 3 | 대협 훈련 (조급함 훈련 자리) | 사용 가능 |
| 4 | 자기자비 | 사용 가능 |

작성 중인 훈련이 있으면 "이어서 하기"와 "새로 시작"을 보여 준다.

### 4.2 불확실성 돌아보기 흐름
상단에 단계 표시: **찾기 → 고르기 → 기록 → 저장**. 뒤로 가기 가능.

**① 찾기 (5분 타이머)**
- 시간대 탭 4개: 아침 / 점심 / 오후 / 저녁. 권장 시간 각 1분 (안내만).
- 각 탭에 흔적 힌트를 항상 보여 준다.
  - 행동: 확인했다, 다시 읽었다, 장면을 되돌려 봤다, 결론 지으려 했다, 깊은 질문을 서둘렀다, 미리 연습했다, 피했다
  - 생각: "왜 그랬지?", "~하면 어떡하지", "아마 ~겠지"
  - 몸: 텐션 상승, 흥분, 조임, 안절부절, 손이 폰으로
  - 감정: 조급함, 답답함, 흥분 뒤 후회
- 흔적 추가 폼:
  - 흔적 종류: 행동 / 생각 / 몸 / 감정 (선택)
  - 흔적 내용 (짧은 텍스트, 필수)
  - "나는 [____]를 모르고, 그게 신경 쓰였다." (빈칸 텍스트, 선택)
- 추가된 흔적은 시간대별 목록으로 보이고, 수정과 삭제가 가능하다.
- 하단 안내: "휴대폰의 메시지 기록이나 사진을 단서로 써도 좋아요."
- 버튼: **다음** / **못 찾음**
- 5분이 지나면 "시간이 됐어요. 여기서 멈추고 다음으로 가요." 배너를 띄운다.

**② 고르기**
- 찾은 흔적 목록을 라디오 버튼으로 보여 준다.
- 안내 문구: "가장 신경 쓰였던 것 하나. 고민하지 말고 바로 골라요."
- "못 찾음"으로 왔다면 이 단계 대신 **지난 기록 업데이트** 화면을 보여 준다.
  - "지난 기록 중 '아직 모름'이었던 것의 결과가 나왔다면 적어요." (텍스트, 선택)
  - 비워 두고 바로 저장 단계로 갈 수 있다.

**③ 기록 (10분 타이머)**
고른 흔적을 상단에 보여 주고 다섯 질문에 답한다. 각 질문 아래에 회색 요령 문구를 둔다.

| # | 질문 | 입력 | 요령 문구 |
|---|---|---|---|
| 1 | 불확실했던 것 | 텍스트 (고른 흔적의 빈칸으로 미리 채움) | |
| 2 | 그때 예상 | 텍스트 + 확신도 슬라이더 0~100% (10 단위) | 지금이 아니라 그때 했던 예상을 써요. |
| 3 | 실제로 일어난 것 | 텍스트 + "아직 모름" 체크박스 (체크하면 텍스트 비활성) | 해석 말고 사실만 써요. |
| 4 | 나는 | 라디오: 머물렀다 / 미뤘다 / 확실성 추구를 했다 | 판단하지 않고 체크만 해요. |
| 5 | 내가 감당했다는 증거 | 텍스트 | "불편했는데 하루가 무너지지 않았다"도 충분해요. |

모든 항목은 선택 입력이다. 비어 있으면 출력에 "(비어 있음)"으로 적는다.

**④ 저장**
- 결과 텍스트 미리보기 (읽기 전용).
- 버튼: **텍스트 파일 다운로드** / **복사** / **홈으로**
- 다운로드 파일명: `uncertainty-YYYY-MM-DD.txt` (사용자의 로컬 날짜 기준)
- 다운로드 후에도 임시 저장은 유지하고, 홈에서 "새로 시작"을 누를 때 지운다.

### 4.3 신체 훈련 흐름
단계: **점수 → 호흡 → 위치 → 머물기 → 저장**. 그날 첫 훈련이라 시작 점수를 여기서 받는다.

- **점수:** 지금 불안, 지금 나를 향한 비난. 각각 0~10 칩. 안내: "지금 상태를 날씨처럼 적어요. 낮추려는 숫자가 아니에요."
- **호흡 (5분):** "호흡 시작"을 누르면 원이 10초 주기로 커졌다 작아지고 "들이쉬기 5 / 내쉬기 5"가 표시된다. 5분이 지나면 배너. 진행 시간을 기록한다. 움직임 줄이기 설정이면 원은 멈추고 글자만 바뀐다.
- **위치 (5분 타이머):** 오늘 가장 텐션이 올랐던 순간(텍스트) + 감각 목록. 감각 하나 = 어디에(칩) + 무엇이(칩 또는 직접 적기) + 강도 0~10. 여러 개 추가, 삭제 가능. 안내: "바꾸려 하지 않아요." 못 찾아도 다음으로 갈 수 있다.
- **머물기 (2분):** 입력 없음. "분석하지 않고, 그 느낌 옆에 그냥 있어요." 진행 시간을 기록한다.
- **저장:** 미리보기, 다운로드(`body-YYYY-MM-DD.txt`), 복사, 홈으로.

### 4.4 자기자비 흐름
단계: **(정의) → 떠올리기 → 편지 → 마무리 → 저장**. 편지는 "자비로운 나"가 장면 속의 나에게 쓴다 (나를 "너"라고 부른다).

- **정의 (처음 한 번):** 지혜로움, 강함, 따뜻함, 표정, 목소리 톤, 자세. 브라우저에 따로 저장되고 매일 불러온다. `compassionate-self.txt`로 내려받을 수 있다. 떠올리기 화면의 "자비로운 나 수정"으로 다시 고친다.
- **떠올리기 (5분 타이머):** 정의한 내용을 띄우고 고정된 안내 다섯 줄을 따른다 (호흡 → 자세 → 표정 → 목소리 → 그 사람이 되어 보기).
- **편지 (8분 타이머):** 장면 선택 두 가지. "오늘 불확실성 기록에서 가져오기"(오늘 고른 흔적이 있을 때만 활성) / "새로 쓰기". 세 칸, 각 칸에 시작 문구를 회색으로 보여 준다.
  1. 알아주기: "그때 너는 ___ 때문에 힘들었구나."
  2. 누구나: "그런 상황에서 그렇게 느끼는 건 ___"
  3. 너에게: "너에게 하고 싶은 말은 ___"
- **마무리:** 와닿은 정도 (와닿음 / 조금 / 공허함, "점수가 아니라 관찰이에요"). 공허함이면 "손을 가슴에 얹고 1분 호흡" 대안이 나온다. 고정 문장: "지금 이런 마음이 있구나. 누구나 그럴 때가 있다. 이대로도 괜찮다."
- **지금은 힘들어요:** 떠올리기, 편지, 마무리 화면에 있다. 누르면 2분 호흡 화면으로 가고, "이어서 하기" 또는 "오늘은 여기까지"(저장으로)를 고른다. 기록에 "중간에 호흡으로 전환"을 남긴다.
- **저장:** `compassion-YYYY-MM-DD.txt`.

### 4.5 대협 훈련
조급함 훈련의 자리. 유비·관우 계열의 "대협"을 인물 설명서로 정하고, 매주 원칙 하나를 정해진 상황(회의, 수업)에서 실천한다. 다른 훈련과 달리 하루에 여러 번 들어오므로 **허브** 구조다.

- **인물 설명서 (처음 한 번, 언제든 수정):** 일곱 원칙(제목, 설명, 행동. 기본값은 `js/data/daehyup.js`), 그림자, 모습(자세, 목소리, 웃음, 말투), 큰 뜻, 고정 상황, 모임 요일(기본 금·토), 시작일(기본 이번 주 월요일). `my-daehyup.txt`로 내려받기.
- **주차:** 시작일부터 7일마다 다음 원칙. 일곱 개를 순환한다.
- **허브:** 이번 주 원칙과 행동 카드, 그리고 아침 출진 / 모임 전 예측(모임 요일만) / 저녁 회고 / 주간 점검(일요일 강조). 오늘 기록 다운로드, 브라우저에 남은 지난 날짜 기록의 다운로드·지우기.
- **아침 출진 (3분):** 설명서 읽기 → 원칙 소리 내어 말하기 → 자세와 호흡 세 번 → 고정 상황에서 할 행동 확인. "출진"을 누르면 완료.
- **모임 전 예측:** 예측 텍스트 + 확신도.
- **저녁 회고 (10분):** 고정 6문항 (이번 주 행동 / 대협이었던 순간 / 떠밀린 순간 / 그때 대협이라면 / 그림자 / 높이 본 사람과 이유).
  - 모임 요일: 관계 실험 결과 (실제 반응, 예측과의 차이).
  - "남을 믿고 높이 본다" 주: 판결 연습 (날짜별로 고정된 문제 2개 + 오늘의 판결 5문항). 문제 은행 30개.
- **주간 점검:** 실행 일수 0~7, 반복된 떠밀린 순간, 메모, 다음 주 원칙 미리보기. `daehyup-week-YYYY-MM-DD.txt`.
- 하루 기록은 날짜별로 브라우저에 저장되고 `daehyup-YYYY-MM-DD.txt`로 내려받는다.

### 4.6 설정과 Google Docs 저장
- **설정 (`#/settings`, 홈 아래 링크):** Apps Script 웹 앱 주소, 비밀 키, 자동 전송 여부. 연결 테스트(ping) 버튼. localStorage에만 저장.
- **저장 화면:** 연결돼 있으면 "Google Docs에 저장" 버튼과 상태 문구. 자동 전송이 켜져 있으면 화면에 오자마자 보낸다. 대협 주간 점검은 버튼으로만.
- **보내는 내용:** `{ date, title, text }`. text는 다운로드 파일과 같은 텍스트. 제목: 신체 훈련 / 불확실성 훈련 / 대협 훈련 / 대협 주간 점검 / 자기자비.
- **문서 구조 (`gas/Code.gs`):** Drive "훈련 기록" 폴더의 "훈련 기록 YYYY-MM" 문서. 섹션 제목(HEADING1) "YYYY-MM-DD · 제목", "■" 줄은 HEADING3. 같은 섹션 제목이 있으면 교체.
- **실패:** 큐에 남겨 두고 앱을 열 때와 설정을 저장할 때 다시 보낸다. 같은 날짜·제목은 최신 것만 남긴다.

## 5. 출력 형식
UTF-8 텍스트. 형식은 고정이며 바꿀 때는 이 문서도 함께 고친다.

```
[불확실성 돌아보기] 2026-10-13 (화)

■ 찾은 흔적
- 아침 | 행동 | 메시지를 몇 번 열어 봄
  → 나는 친구의 반응을 모르고, 그게 신경 쓰였다.
- 오후 | 감정 | 회의 뒤 후회
  → (비어 있음)

■ 기록
1. 불확실했던 것: 친구가 내 메시지를 어떻게 받아들였는지
2. 그때 예상: 내가 너무 진지하다고 생각했을 거야 (확신도 70%)
3. 실제로 일어난 것: 저녁에 평소처럼 답장이 왔다
4. 나는: 확실성 추구를 했다
5. 감당했다는 증거: 불편했지만 오후 일은 다 했다
```

"못 찾음"으로 진행한 경우:

```
[불확실성 돌아보기] 2026-10-13 (화)

■ 찾은 흔적
못 찾음

■ 지난 기록 업데이트
(비어 있음)
```

3번에서 "아직 모름"을 체크한 경우 `3. 실제로 일어난 것: 아직 모름`으로 적는다.

신체 훈련:

```
[신체 훈련] 2026-10-13 (화)

■ 시작 점수
불안: 4/10
나를 향한 비난: (비어 있음)

■ 공명 호흡
5분

■ 감정 위치 찾기
떠올린 순간: 회의에서 말이 빨라졌을 때
- 가슴 | 조임 | 3
- 목·어깨 | 무거움 | 5

■ 그냥 같이 있기
안 함
```

진행 시간이 0이면 "안 함", 그 외에는 "2분 30초"처럼 적는다.

자기자비:

```
[자기자비] 2026-10-13 (화)

■ 장면 (불확실성 기록에서)
메시지를 몇 번 열어 봄

■ 자비의 편지
1. 알아주기: 그때 너는 답을 몰라서 힘들었구나.
2. 누구나: (비어 있음)
3. 너에게: 괜찮아.

■ 와닿은 정도
공허함
대신 손을 가슴에 얹고 1분 호흡

■ 메모
중간에 호흡으로 전환
```

"대신 손을…" 줄은 대안 호흡을 시작했을 때만, "■ 메모"는 "지금은 힘들어요"를 눌렀을 때만 나온다.

대협 훈련 (모임 요일, 판결 연습 주 예시. 해당하지 않는 날은 "■ 모임 전 예측", "■ 관계 실험 결과", "■ 판결 연습"이 빠진다):

```
[대협 훈련] 2026-10-16 (금)
이번 주: 1주차 · 한 박자 뒤에 움직인다
행동: …

■ 아침 출진
했음

■ 모임 전 예측
예측: 어색해질 것이다 (확신도 60%)

■ 저녁 회고
1. 이번 주 행동: 했다
2. 대협이었던 순간: …
3. 떠밀린 순간: …
4. 그때 대협이라면: …
5. 그림자: 떠밀린 서두름
6. 오늘 높이 본 사람: … / 이유: …

■ 관계 실험 결과
실제 반응: …
예측과의 차이: …

■ 판결 연습
[문제 1] …
- 판결: 이건 내가 …(이)라는 뜻이다
- 상황: … / 상대의 상태: … / 상대의 성향: … / 대협이라면: … (각각 한 줄)
[오늘의 판결]
1. 남의 행동: …
2. 내가 읽은 판결: 이건 내가 …(이)라는 뜻이다
3. 다른 가설: 상황 - … / 상대의 상태 - … / 상대의 성향 - …
4. 판결이 맞다고 해도: …
5. 확인 행동: 미뤘다
```

## 6. 파일 구조

```
index.html              진입점. 홈과 흐름 화면을 담는 컨테이너
css/style.css           전체 스타일 (라이트/다크 대응, 모바일 우선)
js/main.js              라우팅 (홈 ↔ 흐름), 훈련 목록 등록
js/flows/body.js        신체 훈련 흐름
js/flows/compassion.js  자기자비 흐름
js/flows/daehyup.js     대협 훈련 (허브)
js/data/daehyup.js      대협 원칙 기본값, 판결 연습 문제 은행
js/flows/uncertainty.js 불확실성 돌아보기 흐름 (화면과 상태)
js/lib/format.js        상태 → 출력 텍스트 (순수 함수)
js/lib/storage.js       localStorage 래퍼 (try/catch)
js/lib/timer.js         단계 타이머
js/lib/download.js      텍스트 파일 다운로드, 클립보드 복사
js/lib/ui.js            공통 화면 도우미 (escape, 단계 표시)
js/lib/sync.js          Google Docs 저장 (설정, 전송, 재시도 큐)
gas/Code.gs             사용자가 배포하는 Apps Script (월별 문서에 쓰기)
tests/format.test.js    출력 형식 테스트
```

새 훈련 추가 = `js/flows/`에 모듈 하나 추가 + `main.js`의 목록에 등록.
