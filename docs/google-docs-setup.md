# Google Docs 자동 저장 설정

훈련을 마치고 저장 화면에 오면, 기록이 내 Google Drive의 **"훈련 기록" 폴더** 안 월별 문서(예: "훈련 기록 2026-10")에 자동으로 쌓인다. 같은 날 같은 훈련을 다시 저장하면 그 날짜의 섹션이 새 내용으로 바뀐다.

처음 한 번, 10분 정도 걸린다.

## 1. Apps Script 프로젝트 만들기
1. https://script.google.com 에 기록을 저장할 Google 계정으로 로그인한다.
2. **새 프로젝트**를 누른다. 왼쪽 위 제목을 "훈련 기록 저장"으로 바꾼다.
3. 편집기에 있는 기본 코드(`function myFunction() {...}`)를 모두 지우고, 이 저장소의 [`gas/Code.gs`](../gas/Code.gs) 내용을 통째로 붙여 넣는다.
4. 저장(디스크 아이콘 또는 Ctrl+S).

## 2. 비밀 키 정하기
비밀 키는 이 스크립트에 기록을 써넣을 수 있는 열쇠다. 길고 아무도 추측 못 할 문자열로 정한다. (예: 영문과 숫자를 섞은 30자 이상)

1. 왼쪽 톱니바퀴 **프로젝트 설정**을 누른다.
2. 아래쪽 **스크립트 속성 → 스크립트 속성 추가**.
3. 속성: `SECRET`, 값: 정한 비밀 키. **스크립트 속성 저장**.

비밀 키는 이 저장소나 다른 곳에 적지 않는다. 앱 설정에만 입력한다.

## 3. 권한 승인 (한 번)
1. 편집기로 돌아가 위쪽 함수 선택에서 `testWrite`를 고르고 **실행**.
2. "승인 필요" 창 → **권한 검토** → 계정 선택.
3. "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 훈련 기록 저장(으)로 이동(안전하지 않음)**. 내가 만든 스크립트라서 나오는 경고다.
4. Drive와 문서 권한을 **허용**.
5. 실행이 끝나면 Drive에 "훈련 기록" 폴더와 "훈련 기록 YYYY-MM" 문서가 생기고, 안에 "연결 테스트" 섹션이 있다. 확인 후 그 섹션은 지워도 된다.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. 유형 선택(톱니바퀴) → **웹 앱**.
3. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.

"모든 사용자"로 해야 앱에서 로그인 없이 보낼 수 있다. 대신 비밀 키가 맞아야만 기록이 써지고, 이 주소로는 기록을 **읽을 수 없다**.

## 5. 앱에 연결
1. 앱 홈 아래쪽 **설정**을 누른다.
2. 웹 앱 URL과 비밀 키를 넣고 **연결 테스트** → "연결됐어요"가 나오면 **저장**.
3. 휴대폰과 PC를 둘 다 쓰면 기기마다 한 번씩 입력한다.

## 동작
- 저장 화면에 오면 자동으로 보내고 "저장됐어요 · 문서 열기"가 뜬다. 자동 전송은 설정에서 끌 수 있고, 그때는 **Google Docs에 저장** 버튼을 누른다.
- 대협 주간 점검은 작성 중에도 같은 화면이라 버튼을 눌렀을 때만 보낸다.
- 인터넷이 끊겨 실패한 기록은 브라우저에 남겨 두었다가, 다음에 앱을 열 때 다시 보낸다.
- 텍스트 파일 다운로드는 그대로 쓸 수 있다.

## 스크립트를 고쳤을 때
`gas/Code.gs`를 바꿔 붙여 넣은 뒤에는 **배포 → 배포 관리 → 편집(연필) → 버전: 새 버전 → 배포**를 해야 반영된다. 이렇게 하면 URL은 그대로다.

## 문제 해결
- **연결하지 못했어요 (unauthorized):** 앱의 비밀 키와 스크립트 속성 `SECRET`이 다르다.
- **연결하지 못했어요 (Failed to fetch 등):** URL이 `/exec`로 끝나는지, 액세스가 "모든 사용자"인지 확인한다.
- **문서를 지웠을 때:** 다음 저장 때 같은 이름으로 새로 만든다.
